# Multilingual-Hate-Speech-Detection.
AI model for detecting hate speech in English,Arabic,and French using XLM-RoBERTa.

## Training & Evaluation Results
The model was successfully trained and evaluated on the multilingual HatEval dataset.

| Language | F1-Score |
| :--- | :--- |
| **English** | 0.77 |
| **Arabic** | 0.75 |
| **French** | 0.75 |
| **Overall (Macro)** | **0.76** |

> **Conclusion:** The model achieved the performance threshold (>0.74) required for Task 14. Detailed training logs can be found in `metrics.txt`.
